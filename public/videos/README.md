# Dossier Vidéos des Projets

## Instructions

Placez ici les vidéos de démonstration de vos 5 projets.

### Fichiers attendus:

1. `kira-demo.mp4` - Démonstration de l'assistant IA Kira
2. `saas-plan-pro-demo.mp4` - Démonstration du générateur de plans d'affaires
3. `saas-annonces-demo.mp4` - Démonstration du scraper d'annonces
4. `ecommerce-parfum-demo.mp4` - Démonstration du site e-commerce de parfums
5. `sites-vitrine-demo.mp4` - Compilation des sites vitrine

### Recommandations techniques:

- **Format**: MP4 (H.264)
- **Résolution**: 1080p ou 720p
- **Durée**: 30-60 secondes par vidéo
- **Taille**: < 10 MB par vidéo (compressez si nécessaire)
- **Framerate**: 30 fps

### Compression avec FFmpeg (si nécessaire):

```bash
ffmpeg -i input.mp4 -vcodec h264 -b:v 2M -b:a 128k output.mp4
```

### Alternative:

Si vous n'avez pas encore les vidéos, vous pouvez:
- Créer des captures d'écran de vos projets
- Utiliser un outil de screen recording (OBS Studio, ShareX)
- Créer des GIFs animés convertis en MP4
